# wordcount —— 词频统计工具

统计文本里每个词出现了多少次，按出现次数从高到低排列。适合快速分析文章、日志、粘贴的文本。

## 编译与运行

```powershell
go run . -file 文章.txt          # 统计某个文件
go run . -file 文章.txt -top 10  # 只看出现最多的 10 个词
type 文章.txt | go run . -top 5  # 从管道读（Windows 用 type）
```

不传 `-file` 时，程序读标准输入：粘贴或重定向文本，Windows 下按 `Ctrl+Z` 回车结束。

## 参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `-file` | 空 | 要统计的文件；不传则读标准输入 |
| `-top` | 0 | 只显示前 N 个词（0 表示全部） |
| `-min` | 1 | 只显示出现次数 ≥ 该值的词（过滤罕见词） |
| `-json` | false | 以 JSON 数组输出（便于管道给其他程序） |

```powershell
go run . -file 文章.txt -min 3        # 只看出现 3 次以上的词
go run . -file 文章.txt -top 10 -json  # 前 10 词，JSON 输出
```

## 切词规则

- 转小写（"Go" 和 "go" 算同一个词）
- 用 `unicode` 判定词字符：**中文等多语言字母也按整词计算**（"语言"、"标准库" 不会被拆成单字）
- 连字符 / 撇号 / 下划线保留在词内（`don't`、`hello-world`、`foo_bar` 算一个词，首尾多余的不算）
- 纯数字也计入词频

## 示例输出

```text
共 52 个词，21 个不同词
词频排行：
  go              5
  the             4
  语言            3
  标准库          2
```
