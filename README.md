# wordcount —— 词频统计工具

一个用 Go 标准库写的命令行小工具，统计文本里每个词出现了多少次，
按出现次数从高到低排列。适合快速分析文章、日志、粘贴的文本。

不依赖任何第三方库。

## 编译与运行

```powershell
go run . -file 文章.txt          # 统计某个文件
go run . -file 文章.txt -top 10  # 只看出现最多的 10 个词
type 文章.txt | go run . -top 5  # 从管道读（Windows 用 type）
```

不传 `-file` 时，程序读标准输入：粘贴或重定向文本，Windows 下按 `Ctrl+Z` 回车结束。

## 参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `-file` | 空 | 要统计的文件；不传则读标准输入 |
| `-top` | 0 | 只显示前 N 个词（0 表示全部） |

## 切词规则

- 转小写（"Go" 和 "go" 算同一个词）
- 按非字母数字字符切分（逗号、句号、空格等都被当作分隔）
- 纯数字也计入词频

## 示例输出

```text
共 52 个词，21 个不同词
词频排行：
  go              5
  the             4
  语言            3
  标准库          2
```
